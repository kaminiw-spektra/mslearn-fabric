# Cloud Scale Analytics with Microsoft Fabric: Fabric IQ, Data Agent & GPU-Accelerated Warehouse

### Overall Estimated Duration : **3 Hours 30 Minutes**

## Overview

Microsoft Fabric is a unified data platform that combines data engineering, data warehousing, data science, and business intelligence tools into a cohesive environment. With the introduction of Fabric IQ, Fabric adds an intelligence layer that captures your organization's business vocabulary as an ontology, grounding every AI experience from Copilot code generation to conversational data agents in shared, governed semantics.

In this hands-on lab, you will activate Fabric IQ across a workspace and put it to work end to end. You will build a data warehouse with a retail star schema, expose it through a semantic model, and generate an ontology that captures the business entities and relationships. You will then run IQ-guided code generation sprints with Copilot in both DAX and Spark, reviewing and validating every piece of generated code before accepting it. Building on that foundation, you will train and compare machine learning models for customer churn, score the customer base, and publish a Fabric Data Agent over the prediction table so stakeholders can query model output in natural language. Finally, you will explore the GPU-accelerated query engine for Fabric Data Warehouse announced at Microsoft Build 2026 and built on NVIDIA accelerated computing by building a scaled multi-million-row workload and establishing a CPU performance baseline using the warehouse's built-in query insights.

## Objective

This lab provides hands-on experience with Fabric IQ, AI-assisted code generation, Fabric Data Agents, and Data Warehouse performance engineering in Microsoft Fabric.

- **Activate Fabric IQ across the workspace and run an IQ-guided code generation sprint in Spark and DAX:** Learn how to create a Fabric workspace on a dedicated capacity, build a data warehouse with a retail star schema, and create a semantic model with relationships. Enable the Fabric IQ preview features at the tenant level and generate an ontology from the semantic model, establishing a shared business vocabulary. Then run Copilot-assisted code generation sprints in DAX query view (building trusted revenue measures) and in a Spark notebook (transforming three years of sales order data), validating all generated code before accepting it.

- **Build a Fabric Data Agent over the trained model output for natural-language model queries:** Learn how to train and compare classification models using Scikit-Learn with MLflow experiment tracking, save the best-performing run as an ML model, and score the full dataset to produce churn predictions stored as a managed Delta table. Then create, instruct, and publish a Fabric Data Agent grounded in the prediction table, and test it with natural-language questions surfacing model insights without writing any SQL or DAX.

- **Add GPU-accelerated Fabric Data Warehouse context:** Learn where the workspace-level Query acceleration (Preview) capability is managed, how the GPU engine routes eligible SQL operations while falling back seamlessly to CPU, and where it delivers the largest gains. Build a scaled analytical workload of approximately two million rows, and use the built-in queryinsights views to measure elapsed time, data scanned, and cache behavior establishing the CPU baseline benchmark used to quantify GPU acceleration.

## Architecture

The architecture leverages a single Microsoft Fabric workspace, hosted on a dedicated F2 capacity, as the shared foundation for all three exercises. It begins with the assignment of the **Fabric Administrator role** and the creation of the **Workspace**, followed by a **Data Warehouse** populated with a retail star schema and exposed through a **Semantic Model** using Direct Lake. With the Fabric IQ tenant settings enabled, an **Ontology** is generated from the semantic model, capturing the business entities and relationships that ground every AI experience in the workspace. **Copilot** then drives IQ-guided code generation sprints in DAX query view against the semantic model, and in a **Notebook** against sales order files stored in a **Lakehouse**.

The second stage extends the foundation into machine learning: a dedicated **Lakehouse** holds the customer churn dataset, a **Notebook** trains and compares classification models tracked by **MLflow**, and the best run is registered as an **ML Model**. The scored predictions are written back to the lakehouse as a managed **Delta table**, over which a **Fabric Data Agent** is created, instructed, and published enabling natural-language queries against the trained model's output. The final stage returns to the Data Warehouse for performance engineering: a scaled multi-million-row workload is built and measured through the built-in **queryinsights** views, establishing the CPU baseline benchmark for evaluating the workspace-level **GPU Query Acceleration** capability powered by NVIDIA accelerated computing.

## Explanation of Components

The architecture for this lab involves the following key components:

- **Fabric Administrator Role:** Ensures that the necessary permissions are granted to manage tenant settings and the workspace effectively, enabling access control and administrative capabilities.

- **Workspace on F2 Capacity:** A central environment, assigned to a pre-provisioned Fabric capacity, where all items across the three exercises are created and managed. A single shared workspace hosts the entire lab.

- **Data Warehouse:** A fully transactional data warehouse holding the retail star schema (DimProduct, DimCustomer, DimDate, FactSalesOrder) built with T-SQL, and later a scaled fact table used for performance benchmarking.

- **Semantic Model (Direct Lake):** Exposes the warehouse tables for analysis with defined relationships, serves as the source for ontology generation, and hosts the Copilot-assisted DAX sprint in DAX query view.

- **Fabric IQ Ontology:** Generated from the semantic model, the ontology captures business entities and relationships as a shared vocabulary the semantic foundation that grounds Copilot experiences and the Data Agent.

- **Lakehouses:** Scalable storage combining files and Delta tables. One lakehouse holds raw sales order files for the Spark sprint; a second holds the churn dataset and the scored prediction table, keeping the Data Agent's grounding data cleanly scoped.

- **Notebooks with Copilot:** Interactive PySpark environments used for the IQ-guided Spark code generation sprint and for the machine learning workflow, with notebook Copilot generating code that is reviewed and validated before acceptance.

- **MLflow Experiment and ML Model:** MLflow autologging tracks training runs for comparison; the best-performing run is registered as a versioned ML model and reloaded for batch scoring.

- **Fabric Data Agent:** A conversational agent grounded in the churn prediction table, configured with agent instructions and example queries, published for workspace use, and tested with natural-language questions.

- **GPU Query Acceleration (Preview):** A workspace-level capability, built on NVIDIA accelerated computing, that routes eligible SQL operations to GPU execution. The lab establishes the CPU baseline using **queryinsights** the benchmark re-run to quantify GPU gains once a tenant is onboarded to the early access program.
